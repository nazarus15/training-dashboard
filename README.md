# Гілка journal: дані, які пише сам сайт

- `logs.json` — записи силового журналу (strength.html). Не редагуй вручну під час тренування.
- `planned.json` — заплановані тренування для Планера, Календаря, Огляду і журналу.

Сайт читає ці файли напряму, тому зміни тут не перезбирають сайт: досить закомітити файл.

## planned.json

```json
{
 "workouts": [
  { "id": "w-2026-11-10-a1b2", "date": "2026-11-10", "sport": "strength", "title": "Сила А", "text": "…текст тренування…" },
  { "id": "w-2026-11-12-c3d4", "date": "2026-11-12", "sport": "bjj", "title": "Відкритий килим", "mins": 90, "time": "19:00" }
 ],
 "recurring": [
  { "sport": "bjj", "title": "БЖЖ", "days": [1, 3, 5], "mins": 90, "time": "19:00", "from": "2026-10-26", "until": null, "skip": [] }
 ]
}
```

- `sport`: `strength`, `bjj`, `run`, `other`. Вело планується в intervals.icu, сайт бере його звідти.
- `id` не міняти після першого тренування: до нього прив'язані записи журналу.
- `mins` для силового необов'язковий: сайт рахує тривалість з тексту.
- `recurring.days`: 1 = пн … 7 = нд. `skip` — дати, коли регулярного тренування не буде.

## Текстовий формат силового

```
Мета: Задня ланка і жим над головою.

Розминка 8–10 хв
- Гоблет-присід з паузою — 2x8
- Легкі махи гирею — 1x10

A
- Румунська тяга 4x6 @штанга відп 90с RIR 2-3 // Таз назад, спина рівна
- Підтягування зворотним хватом 4x5-8 @вага тіла відп 90с // Перший раз: стільки, скільки чисто

Коло 3x відп 2хв
- Віджимання 15
- Планка 40с
- Махи гирею 20 @24кг

Заминка
- Розтяжка стегон 5хв
```

Рядок, що починається з `-`, — вправа. Рядок без `-` — заголовок блоку.

| Що | Як писати | Приклади |
|---|---|---|
| Підходи × повтори | `NxR` після назви | `4x6`, `3x8-12`, `3xmax`, `3x40с`, `2x1хв` |
| На кожен бік | `/бік` одразу після повторів | `3x8/бік`, `2x30с/бік` |
| Вага або снаряд | `@…` | `@штанга`, `@60кг`, `@гиря`, `@24кг`, `@вага тіла`, `@+10кг` |
| Відпочинок | `відп …` | `відп 90с`, `відп 2хв`, `відп 2:30` (без одиниць: до 5 — хвилини) |
| Запас повторів | `RIR …` або `запас …` | `RIR 2`, `RIR 1-2` |
| Підказка | `// текст` | `// Лікті під 45°`; `// Перший раз: …` показується, поки немає історії |
| Ефект вручну | `#тег` | `#сила`, `#гіпертрофія`, `#витривалість`, `#потужність`, `#кор` |

Заголовки блоків:
- `Розминка 8–10 хв`, `Заминка` — пункти показуються простим списком, підходи не записуються.
- `A`, `B`, `Суперсет`, будь-яка назва — блок вправ; вправи блоку йдуть по черзі (суперсет).
- `Коло 3x` — коло: у вправах можна писати лише повтори (`Віджимання 15`), підходів буде 3.
- `… відп 2хв` у заголовку — відпочинок для всіх вправ блоку, якщо у вправи свій не вказано.
- `Мета: …` — опис під назвою. `Тривалість: 45 хв` — замість автоматичного розрахунку.

Тип вводу в журналі визначається сам: повтори на час → секунди; `@гиря` чи «гир» у назві → гиря;
`@вага тіла`, підтягування, віджимання → вага тіла (+кг); інакше штанга (кг).
Історія і прогрес вправ зв'язуються за назвою: пиши назву однаково в різних тренуваннях.

## Ефекти

Сайт визначає ефекти сам. Силові: кожен робочий підхід (не розминка) зараховується до одного ефекту:
тег → «Кор і стабільність» за назвою (планки, турецький підйом, прес, перенесення) → «Потужність»
(махи, стрибки, поштовхи) → за повторами: до 6 — Сила, 7–12 — Гіпертрофія, 13+ / на час / max — Силова витривалість.
100 = 10 підходів сили, 12 гіпертрофії, 10 витривалості, 8 потужності, 8 кору.

Вело: з хвилин у зонах плану intervals.icu. 100 = 90 хв Z2 (Z1 рахується наполовину), 40 хв темпу,
40 хв sweet spot, 30 хв порогу, 20 хв VO2max, 5 хв анаеробної.
