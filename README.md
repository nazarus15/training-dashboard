# Форма Назара

Дашборд тренувального стану: навантаження, відновлення, потужність і журнал активностей.
Дані оновлюються двічі на день за Києвом — о 23:00 і о 10:00 (якщо о 10:00 не прийшли свіжі дані сну або intervals, о 12:00 буде один повтор) — через GitHub Actions, без участі Claude і без увімкненого комп'ютера.

- **intervals.icu** — офіційний API за особистим ключем: wellness, активності, крива потужності, зони.
- **Garmin Connect** — офіційний [Personal API](https://developer.garmin.com/gc-developer-program/personal/personal-api) за особистим ключем: сон з фазами й нічними кривими, HRV, Body Battery, стрес, пульс спокою, SpO₂, фітнес-вік і всі тренування з навантаженням Garmin та Training Effect. Готовність, гостре/хронічне навантаження і баланс сайт рахує сам: Personal API їх не віддає.

## Налаштування (один раз)

1. **Settings → Pages**: Source — `Deploy from a branch`, гілка `main`, тека `/ (root)`.
2. **Settings → Actions → General → Workflow permissions**: `Read and write permissions`.
3. **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Звідки взяти |
|---|---|
| `INTERVALS_API_KEY` | intervals.icu → Settings → Developer Settings → API key |
| `GARMIN_PERSONAL_API_KEY` | connect.garmin.com/app/settings/personalApiToken → Create Key, термін 1 рік |

4. **Actions → Оновлення даних → Run workflow** — перший запуск вручну.

## Коли Garmin показує помилку

- «Ключ Garmin недійсний або протермінований» — ключ живе максимум рік. Створи новий там само і заміни секрет `GARMIN_PERSONAL_API_KEY`.
- Помилки окремих запитів — деталі в плашці на сайті і в журналі запуску (рядок `GARMIN DISCOVERY` показує структуру відповідей без значень).

## Файли

- `index.html`, `app.js` — огляд стану; `strength.html`, `strength.js` — силовий журнал.
- `planned.json` у гілці `journal` — заплановані силові, БЖЖ та інше (Планер). Формат тексту тренувань і правила ефектів — у README гілки journal.
- `workout.js`, `workout.css` — спільне для всіх сторінок: ефекти з незмінними назвами, розбір тексту силових, злиття плану з календарем intervals.icu.
- `planner.html` — Планер: створення й редагування запланованих тренувань із живим переглядом.
- `calendar.html` — Календар по місяцях: план (вело з intervals.icu, решта з Планера) і виконані тренування з позначками.
- `settings.html` — Налаштування: стан системи (оновлення даних, токен, журнал; вкладка підсвічується, якщо щось не так), конструктор огляду, токен GitHub, пароль і код відновлення, нижня межа FTP для перцентиля, розклад БЖЖ, контекст для ШІ.
- `export.js` — експорт стану й аналітики текстом для ШІ, правила формату силових для промпту, імпорт відповіді ШІ (у Планері).

## Пароль і шифрування
- Особисті дані (`data/wellness|activities|power|garmin.enc`, журнал `logs.json`, приватна частина `settings.json`) зашифровані: AES-256-GCM + RSA-OAEP-3072 з публічним ключем `pubkey.json`. Workflow шифрує лише публічним ключем, секретів не потребує.
- Приватний ключ лежить у `keyring.json`, зашифрований паролем (PBKDF2-SHA256, 600 тис. ітерацій). Після входу ключ зберігається в IndexedDB браузера як невитягуваний.
- Пароль змінюється в Налаштуваннях. Якщо пароль втрачено: `python scripts/new_keys.py "новий пароль"`, закомітити `pubkey.json` і `keyring.json`, запустити оновлення даних.
- Відкриті: план (`planned.json`, `events.json`), `status.json`, таблиця рангів.
- Гілка `journal`, файл `logs.json` — записи силового журналу. Сторінка пише їх через GitHub API особистим fine-grained токеном (лише цей репозиторій, Contents: Read and write), який зберігається тільки в браузері.
- `data/*.json` — дані, які оновлює workflow; `data/status.json` — стан останніх запусків.
- `scripts/fetch.py` — збір даних.
- `.github/workflows/update.yml` — тригери на обидва часові пояси (літній і зимовий) з запасом на затримки GitHub; `scripts/gate.py` вирішує, чи запускати збір: вечір (один раз після 23:00), ранок (один раз після 10:00), повтор о 12:00 лише якщо ранковий збір не дав сну за сьогодні або впав.

> Репозиторій публічний: усі дані з `data/` (HRV, сон, вага, пульс) видно будь-кому.
