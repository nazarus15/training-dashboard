Збереження на GitHub

Як отримати токен (2 хв)
  1. Відкрий github.com → Fine-grained token.
  2. Назва «Форма», термін — 1 рік. Repository access → Only select repositories → training-dashboard.
  3. Permissions → Repository permissions → Contents: Read and write. Generate token, скопіюй і встав сюди.
  4. Токен зберігається лише в цьому браузері. Потрібен для журналу, Планера і цих налаштувань.

Вже є токен, але лише на читання? Не створюй новий: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → твій токен → Edit → Repository permissions → Contents: Read and write → Update. Потім встав той самий токен сюди ще раз.

Пароль сайту

Дані на сайті й у репозиторії зашифровані, пароль їх відкриває. Пристрої, де вже виконано вхід, після зміни пароля лишаються залогіненими. Якщо пароль забути, його не відновити — доведеться створити нові ключі (попроси Claude).

Базові метрики
