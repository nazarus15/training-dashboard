Збереження на GitHub

Як отримати токен (2 хв)
  1. Відкрий github.com → Fine-grained token.
  2. Назва «Форма», термін — 1 рік. Repository access → Only select repositories → training-dashboard.
  3. Permissions → Repository permissions → Contents: Read and write. Generate token, скопіюй і встав сюди.
  4. Токен зберігається лише в цьому браузері. Потрібен для журналу, Планера і цих налаштувань.

Вже є токен, але лише на читання? Не створюй новий: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → твій токен → Edit → Repository permissions → Contents: Read and write → Update. Потім встав той самий токен сюди ще раз.

Google Calendar

Приватна синхронізація: тренування йдуть прямо у твій календар «Тренування · Форма» через твій власний скрипт Google (Apps Script). Публічно нічого не з'являється.

  • План вело, силових і БЖЖ — на весь день або у свій час; вело розгорнуте у вати.
  • Виконане з Garmin — фактичний час, пульс, навантаження, позначка ✓ (з кожним оновленням даних).
  • Силові з журналу — старт, фініш, підходи; оновлюється за хвилину після «Почати» чи «Завершити».

Публічний календар-підписка (лише план)

Старий варіант без виконаних тренувань: https://nazarus15.github.io/training-dashboard/data/calendar.ics. Якщо підключив приватний календар — цю підписку в Google Calendar краще видалити, щоб події не дублювались.

Пароль сайту

Ти увійшов кодом відновлення. Задай новий пароль: у поле «Поточний» встав той самий код.

Дані на сайті й у репозиторії зашифровані, пароль їх відкриває. Пристрої, де вже виконано вхід, після зміни пароля лишаються залогіненими. Якщо забудеш пароль, увійди кодом відновлення (нижче) і задай новий.
